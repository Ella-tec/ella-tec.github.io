# Eliyas Eshtea — Personal Portfolio

A responsive, editorial-style portfolio website built with semantic HTML, CSS, and vanilla JavaScript. It is intentionally dependency-free, so it can be opened in Visual Studio Code and deployed directly with GitHub Pages.

## Included

- Responsive landing page and mobile navigation
- About, expertise, selected projects, journey, and contact sections
- Project links to FINOVA, Mela, ISACA Trusted Resource, and earlier GitHub work
- Scroll reveal effects with reduced-motion support
- Custom favicon, metadata, and accessible navigation labels
- No build step and no package installation required

## Run locally in VS Code

1. Clone the repository:
   ```bash
   git clone https://github.com/Ella-tec/ella-tec.github.io.git
   ```
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension and choose **Open with Live Server**.
4. You can also run a local server from the project folder:
   ```bash
   python -m http.server 5500
   ```
   Then visit http://localhost:5500.

## Deploy with GitHub Pages

This repository is named `ella-tec.github.io`, so it can be published as the account's GitHub Pages site.

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the Pages deployment to finish. The site address is https://ella-tec.github.io/.
